PRE-FIRST-BYTE VS MID-STREAM

Silent failover only occurs before the first token renders—with live cooldown ETAs and health badges. Once output has started streaming, silent switching is strictly blocked to prevent corrupted mixed-model responses; instead, an interactive notice pill lets you retry cleanly.

02ARCHITECTURE & CAPABILITIES

Built for control, hardened down to the filesystem.

Every subsystem in VersaRail AI is engineered to eliminate silent overwrites, credential leaks, and fragile native C++ builds.

Diff-First Mutation Engine & Conflict Detection

Agents cannot overwrite files blindly. VersaRail inspects baseline SHA-256 hashes, renders unified patches in DiffViewer for human review, detects external disk edits before commit, and writes atomically via temp file + fsync + rename.

1. sha256(baseline)→2. DiffViewer review→3. fsync + rename

TOCTOU-Hardened Permission Broker

Every approved tool call binds its exact arguments to a canonical SHA-256 hash. If parameters mutate before execution, ToctouTamperingError aborts the run. Path traversal, symlinks, and .env/.git/.ssh paths are blocked via realpath.

Canonical SHA-256 binding ENFORCED

Dual-Path Terminal Architecture

Pairs an interactive developer xterm.js shell with a sandboxed AgentCommandRunner using structured arg arrays, 1 MB output caps, strict timeouts, secret redaction, and recursive process-tree termination via tree-kill.

args[] → 1MB cap + redact → tree-kill

Zero Native Build Toolchains

Built on Node.js 24's built-in node:sqlite (DatabaseSync in WAL mode) and native fetch—zero node-gyp, MSBuild, or Python compilation headaches across Windows, macOS, and Linux.

Context Budgeting, Quotas & Privacy Purging

Track provider rate limits in UsageQuotasView, manage multi-step plans in TodoDock, auto-summarize long threads near context floors, and purge local SQLite retention logs on your own schedule.

03SECURITY POSTURE

Offline-first renderer and compile-time Electron fuses.

Security isn't a settings checkbox—it's compiled into the binary and enforced at every IPC boundary.

OS HARDWARE KEYRING

Electron safeStorage

API keys stay encrypted in your host OS keychain and are never leaked to the renderer. Linux basic_text unencrypted persistence is explicitly refused.

BINARY HARDENING

@electron/fuses

Packaged builds flip RunAsNode: false, OnlyLoadAppFromAsar: true, EnableNodeCliInspectArguments: false, and ASAR integrity checks.

ZERO TELEMETRY / ZERO CDNs

Strict connect-src 'none'

All Lucide icons, provider SVGs, and typography are bundled offline. The production renderer blocks external network calls; only the main process talks to your chosen provider.

DEVELOPER GIT POLICY

Human-Controlled Git

VersaRail AI never executes autonomous git commit or git push commands. Changes stay cleanly in your working tree until you inspect and commit them yourself.
