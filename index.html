02CAPABILITIES & SECURITY

Built for verifiable local control.

Every model request, file edit, and command stays transparent and auditable on your machine.

Multi-Provider Failover

Bring 13 built-in adapters plus custom local Ollama and OpenAI-compatible gateways. Rate limits or server errors switch backups before the first token renders.

Diff-First Atomic Edits

Review every proposed change as a unified diff before anything hits disk. File hashes detect external modifications so writes apply cleanly and atomically.

Verified Tool Approvals

File mutations and sandboxed commands—with elevated actions like git push flagged explicitly—are locked to your approved arguments with timeouts, output caps, and secret redaction.

Usage & Quota Tracking

Track 24-hour and monthly token usage, free-tier budgets, and live provider cooldown timers from one workspace view.

OS Keychain Encryption

API keys stay encrypted inside Windows DPAPI, macOS Keychain, or Linux Secret Service—never stored in unencrypted plaintext files.

Local-First & Zero Telemetry

Multi-thread chats, @ file mentions, context budgets, and configurable history purges live in local SQLite inside an offline desktop UI.
